# dsh-web-browser 抖音宣传片 · 原创 BGM + 8 句 VO 混音

30.0s 竖屏宣传片（1080×1920 / 30fps）的音频成品。BGM 全部由 numpy/scipy 程序化合成，
**不含任何版权采样、歌曲或人声素材**；混音把 8 句 edge-tts 配音（`zh-CN-YunxiNeural`，云希男声）
按 `work/timeline.json` 做样本级落位。

- 生成脚本：`bgm_script.py`（一条命令全量复现）
- 测量原始数据：`_build/report.json`
- VO 源文件：`vo/line01..08.wav`（48kHz 单声道，edge-tts +14%~+16% 语速）

## 交付物

| 文件 | 规格 | 响度 / 峰值 | 用途 |
|---|---|---|---|
| `bgm.wav` | 30.000s · 48kHz · 2ch · 24bit PCM | **-17.0 LUFS** / TP -4.7 dBTP | BGM 单独版（试听、备用、替换基准） |
| `mix.wav` | 30.000s · 48kHz · 2ch · 24bit PCM | **-14.0 LUFS** / TP -1.7 dBTP | 成片混音，直接给视频合成 |
| `bgm_only.mp3` | 30.000s · 48kHz · 2ch · 192kbps | 同 `bgm.wav` | 快速试听 |
| `bgm_script.py` | Python3 + numpy/scipy + ffmpeg | — | 合成 + 混音 + 自检 |

## 一、音乐设计

| 项 | 值 |
|---|---|
| 速度 / 拍号 | 120 BPM / 4/4，1 小节 = 2.0s，15 小节 = 30.000s |
| 调性 | A 小调，和声循环 **Am7 – Fmaj7 – Cmaj7 – Gadd9**（温暖、无强导向音，不抢人声） |
| 音色 | 深 sub、小底鼓、干净 hats、暖 pluck 琶音、暖 pad、FM 钟声点缀、噪声 riser、画面切点 impact |
| 混响 | 自制短 Schroeder（4 comb + 2 allpass，RT≈0.8s），**只送 pad/pluck/bell 约 22%**，保持干爽 |
| 留白 | 13.33–16.5（主页场景）抽掉 kick/hats，只留 pad + 稀疏 pluck + 降 4dB 的 sub |

全部音色用正弦/锯齿/噪声 + biquad 滤波 + 指数包络合成，随机数固定种子 `20261105`，
同代码重跑结果逐样本一致。

## 二、结构时间线

## 三、混音与母带链

```
BGM 总线（各音色总线求和 + 混响 send）
  → 轻压缩 2:1 @ -18dBFS（60ms 窗，收 impact 峰值）
  → 母带：线性增益 + 前瞻峰值限幅（-1.5dBFS）→ bgm.wav = -17.0 LUFS
                                           └→ 进混音，先乘 duck 包络

VO：line01..08
  → 低切 85Hz（2 阶 BW，给人声让低频）
  → 压缩① 3:1 @ -22dBFS（25ms 窗）→ 压缩② 4:1 @ -14dBFS（10ms 窗）
  → 每句归一到 VO 总线 -16.5 LUFS（单声道 stem -19.5，双单声 +3.01dB）
  → 峰值收口 crest ≤ 12.5dB（前瞻 4ms）
  → 按 timeline.start 样本级落位（L/R 各一份，居中）

混音 = duck(bgm) + vo
  → 低切 25Hz → 总线轻压缩 1.8:1 @ -16dBFS
  → 母带：增益 +3.90dB，限幅 -1.7dBFS（最大 GR 仅 0.61dB）→ mix.wav = -14.0 LUFS

Duck：深度 10.0dB，pre 120ms / post 300ms 余弦斜坡，
      合并后的压低区间 = [0.300, 28.256] → 释放到 28.556s（让 29.2 终结重音回到满电平）
```

采用**看前静态包络**而不是逐样本 sidechain：人声时间表已知，静态包络不会抽吸、
压低量可精确测量，且 0.14s 的句间空隙不会让音乐来回泵动。

### 4.5 其他自检

- `mix.wav` 28.3–30.0s：VO stem = -200.7dB（无信号），BGM = -20.7dB，mix = -17.3dB → **片尾只有 BGM 收尾**。
- mix 各句 0.4s 抽检窗（VO 起点 +0.2~0.6s）：-13.4 / -13.2 / -13.1 / -12.8 / -12.7 / -12.7 / -11.2 / -12.9 dB，
  8 句均在应有位置有信号。
- 削波：`max_volume = -1.70 dBFS`，无 0dBFS 采样；DC ≈ 0。
- 整体 crest ≈ 12.1dB；限幅器最大衰减 0.61dB → 没有靠硬压换响度。
- 频谱平衡（相对 500–1k 频段）：20–60Hz +12.7、60–120Hz +8.5、120–250Hz +1.6、2–4k -13.1、4–8k -18.1 dB
  → 低频厚但不浑浊，高频不刺（符合「不要高频刺耳」）。

## 五、复现 / 替换 BGM / 重混

### 全量复现（约 10s）

```bash
cd _会话/_实体/20261105-f1d59c38/audio
python3 bgm_script.py                 # 合成 → 母带 → 混音 → 自检 → 导出 mp3
```

依赖：`python3` + `numpy` + `scipy` + `ffmpeg/ffprobe`。输出会覆盖 `bgm.wav`/`mix.wav`/`bgm_only.mp3`，
测量写入 `_build/report.json`。加 `--keep` 保留 VO stem 等中间文件，`--no-mp3` 跳过 MP3。

### 换 BGM 曲子（保留 VO 与 duck）

```bash
python3 bgm_script.py --bgm-from /path/to/other_track.wav --no-mp3
```

脚本会自动：任意采样率 → 48kHz（polyphase 重采样）、单声道 → 双声道、裁/补到 30.000s、
归一到 -17.0 LUFS，然后走同一条 duck + 混音 + 母带链。

已验证回灌闭环：用本目录 `bgm.wav` 作为 `--bgm-from` 输入，输出的 `mix.wav` 与直接合成版
响度差 0.01 LU、整片 RMS 差 -29dB（差异只来自二次母带的增益细节）。

### 常用参数（`bgm_script.py` 顶部常量）

| 常量 | 默认 | 含义 |
|---|---|---|
| `DUCK_DB` | 10.0 | 人声段 BGM 压低量（8–12 可调） |
| `VO_LINE_LUFS` | -16.5 | VO 总线响度目标（相对 BGM 的平衡由它决定） |
| `BGM_LUFS` | -17.0 | `bgm.wav` 母带电平 |
| `MIX_LUFS` | -14.0 | `mix.wav` 目标响度 |
| `CEIL_DB` | -1.7 | 母带采样峰值天花板（真峰值留余量） |
| `VO_CREST_DB` | 12.5 | 单句人声 crest 上限（越小越「贴脸」，越大越自然） |
| `BGM_BUS_COMP` | (-18, 2.0) | BGM 总线压缩（阈值 dB, 压缩比） |
| `PAD_AUTO` / `SUB_AUTO` | — | 段落电平自动化关键点 |
| `IMPACTS` / `RISERS` / `BELLS` | — | 打击点 / 升腾 / 钟声时间表 |
| `CHORD_BY_BAR` | — | 每小节和弦（改这里即可换和声，配 `CHORDS`/`ROOTS`） |

### 换 VO 时间

改 `../work/timeline.json` 的 `vo[].start/dur/end` 后重跑即可（duck 区间、VO 落位、
silencedetect 自检都会自动跟着变）。VO 文件本身放在 `vo/line01..08.wav`。

## 六、已知取舍

1. **鼓组在 4.0s 落定，而不是 3.358s**：3.358 的大 impact 已经承担了「揭晓」的低频重击，
   3.5/3.75 两个 hats 做桥接，鼓组落在下一个整小节。若强行把 kick 对齐 3.358，
   会与 impact 的 sub 尾音撞出 142ms 的双低频 flam，更脏。
2. **BGM 整段压在 VO 下 10.5dB**：这是人声主导型短视频的标准做法；BGM 单独听会显得
   动态偏平（LRA 1.4LU），成品里靠段落配器变化而不是音量变化来推进。
3. **`bgm.wav` 是 -17 LUFS 试听电平**，比它在 `mix.wav` 里的实际位置（母带 +3.9dB 后）低约 3.9dB。
   换曲或重混时以 `bgm.wav` 为基准电平（脚本里按 -17 归一化），不要用「听起来」的相对音量对齐。
